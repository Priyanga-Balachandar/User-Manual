# Mobile Phone User Manual

## 1. Introduction

This user manual provides instructions for operating the XYZ Mobile Phone.
It covers basic phone functions, charging, calling, messaging, camera usage,
internet connectivity, and safety precautions.

## 2. Product Overview

The mobile phone includes the following features:

- 6.5-inch touchscreen display
- 5000 mAh battery
- 50 MP rear camera
- 8 MP front camera
- 128 GB internal storage
- 4G/5G network support
- Wi-Fi and Bluetooth connectivity
- USB Type-C charging port
- Fingerprint sensor

## 3. Getting Started

### 3.1 Installing the SIM Card

1. Switch off the mobile phone.
2. Insert the SIM ejector tool into the SIM tray hole.
3. Remove the SIM tray.
4. Place the SIM card correctly in the tray.
5. Insert the tray back into the phone.
6. Switch on the phone.

### 3.2 Powering On the Phone

1. Press and hold the Power button for approximately 3 seconds.
2. Release the button when the manufacturer logo appears.
3. Wait for the phone to complete the startup process.

### 3.3 Charging the Phone

1. Connect the USB Type-C cable to the charging port.
2. Connect the other end to the supplied power adapter.
3. Connect the adapter to a power outlet.
4. The battery charging indicator appears on the screen.

## 4. Basic Operations

### 4.1 Making a Call

1. Open the Phone application.
2. Enter the required phone number.
3. Tap the Call button.
4. To end the call, tap the End Call button.

### 4.2 Sending a Message

1. Open the Messages application.
2. Select New Message.
3. Enter the recipient's phone number.
4. Type the message.
5. Tap Send.

## 5. Camera

### 5.1 Taking a Photo

1. Open the Camera application.
2. Point the camera toward the subject.
3. Adjust the focus if required.
4. Tap the Shutter button to capture the image.

### 5.2 Recording a Video

1. Open the Camera application.
2. Select Video mode.
3. Tap the Record button.
4. Tap the Stop button to finish recording.

## 6. Connecting to Wi-Fi

1. Open Settings.
2. Select Wi-Fi.
3. Enable Wi-Fi.
4. Select the required network.
5. Enter the password.
6. Tap Connect.

## 7. Bluetooth

1. Open Settings.
2. Select Bluetooth.
3. Enable Bluetooth.
4. Select the required device.
5. Confirm the pairing request on both devices.

## 8. Safety Precautions

- Use only compatible charging accessories.
- Do not expose the phone to excessive heat or moisture.
- Do not use damaged charging cables.
- Keep the phone away from water unless it is specifically rated for water resistance.
- Do not attempt to disassemble the phone.
- Keep the device and accessories away from children.

## 9. Troubleshooting

| Problem | Possible Solution |
|:---:|:---:|
| Phone does not switch on | Charge the battery and try again. |
| Phone is not charging | Check the cable, adapter, and charging port. |
| No network connection | Check SIM card and network settings. |
| Wi-Fi is not connecting | Check the Wi-Fi password and restart Wi-Fi. |
| Phone is slow | Close unused applications and restart the phone. |
| Camera is not working | Close and reopen the Camera application. |
